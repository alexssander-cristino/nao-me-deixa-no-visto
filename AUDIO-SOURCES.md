# Fontes de áudio — Não Me Deixa no Visto

A biblioteca SFXMint declara os arquivos CC0 1.0, permite uso comercial e hotlink, e informa que o catálogo é gerado por IA/síntese procedural. Portanto, são efeitos licenciados reais em formato MP3, mas **não são gravações humanas nem falas originais de Valdirene/Anderson**.

## Pendência de produção

Para identidade vocal autêntica, ainda devem ser gravados ou licenciados:
- Falas em português brasileiro de Valdirene.
- Risadas, sussurros e respiração gravados especificamente para Valdirene.
- Falas, respiração e gritos originais de Anderson.
- Variações de voz sincronizadas com as animações faciais.

O jogo mantém a Web Audio API para efeitos procedurais e usa os MP3 acima como camada adicional. Se um servidor externo estiver indisponível, os efeitos procedurais existentes continuam disponíveis.
