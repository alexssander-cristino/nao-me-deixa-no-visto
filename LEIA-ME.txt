# Ela Não Aceita o Fim — versão desktop

Este projeto empacota o HTML original como aplicativo Windows usando Electron.
O Three.js foi configurado para ser carregado localmente pelo pacote `three`,
em vez de depender da CDN usada na versão original.

## Requisitos
- Windows 10/11
- Node.js LTS instalado
- Conexão com a internet na primeira instalação das dependências

## Executar para testar
Abra o terminal nesta pasta e rode:

```bash
npm install
npm start
```

## Gerar o instalador e o pacote
```bash
npm run make
```

Os arquivos de distribuição serão criados dentro da pasta `out/`.
O instalador do Windows (Squirrel) normalmente fica em:

`out/make/squirrel.windows/x64/`

## Controles do jogo
- WASD: mover
- Shift: correr
- F: lanterna
- E: interagir
- Mouse: olhar
- Esc: pausar
- F11: alternar tela cheia da janela

## Observações
- O HTML e a lógica original do jogo foram preservados, exceto pela troca
  da URL do Three.js para o caminho local.
- A primeira execução de `npm install` precisa baixar Electron, Forge e Three.js.
- O instalador gerado não é assinado digitalmente; o Windows pode exibir um
  aviso do SmartScreen ao executar.
