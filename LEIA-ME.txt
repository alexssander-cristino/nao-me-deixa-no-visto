# Não Me Deixa no Visto — versão desktop

Este projeto empacota o HTML original como aplicativo Windows usando Electron.
O Three.js foi configurado para ser carregado localmente pelo pacote `three`,
em vez de depender da CDN usada na versão original.

## Requisitos
- Windows 10/11
- Node.js LTS instalado
- Conexão com a internet na primeira instalação das dependências

## Executar para testar
Abra o terminal nesta pasta e rode:

```bash
npm install
npm start
```

## Gerar o instalador e o pacote
```bash
npm run make
```

Os arquivos de distribuição serão criados dentro da pasta `out/`.
O instalador do Windows (Squirrel) normalmente fica em:

`out/make/squirrel.windows/x64/`

## Controles do jogo
- WASD: mover
- Shift: correr
- Ctrl: agachar e reduzir o ruído
- F: lanterna
- E: interagir
- Mouse: olhar (sensibilidade ajustável nas configurações)
- Lanterna: feixe direcional, bateria e oscilação quando está fraca
- Esc: pausar
- F11: alternar tela cheia da janela
- Dificuldade: ajuste nas configurações (Tranquilo, Normal ou Sem misericórdia)

## Observações
- O jogo usa Three.js local e inclui modelo humanoide procedural para Valdirene,
  iluminação e feixe da lanterna aprimorados, decoração procedural dos cenários,
  controles ajustados, agachamento e áudio de passos.
- A primeira execução de `npm install` precisa baixar Electron, Forge e Three.js.
- O instalador gerado não é assinado digitalmente; o Windows pode exibir um
  aviso do SmartScreen ao executar.


## Novidades da versão 1.3.0
- Qualidade gráfica escalável: Desempenho, Equilibrada e Alta.
- Campo de visão ajustável nas configurações.
- Partículas de poeira animadas para reforçar a atmosfera dos ambientes.
- Áudio espacial HRTF com posicionamento de fontes sonoras.
- Valdirene reage aos ruídos de passos e corrida; agachar reduz o alcance de detecção.
- A entidade pode desaparecer quando observada diretamente durante a patrulha.


## Reconstrução técnica 2.0.0

A versão 2.0 inicia a separação dos sistemas que antes estavam concentrados no HTML:

- \`physics.js\`: colisão contínua 2.5D, círculos contra caixas orientadas, resolução de penetração, obstáculos móveis e raycast.
- \`controller.js\`: controlador FPS reutilizável com aceleração, desaceleração, corrida, agachamento, altura de câmera amortecida e resposta às colisões.
- \`models.js\`: modelo procedural de Valdirene com vestido em malha de revolução, cabelo em mechas, véu, detalhes faciais e pivôs de animação.
- Materiais do cenário: texturas procedurais de 512 × 512, bump mapping e materiais PBR de alta rugosidade.
- Portas: painéis com molduras, relevos, dobradiças e ferragens; seus colisores acompanham a rotação da folha.

### Testes de física

Execute \`npm test\` para rodar os testes de regressão da camada de colisão.

### Limites desta etapa

A física implementada é um controlador de colisão 2.5D para personagem e cenário, não um solver completo de corpos rígidos 3D. Objetos dinâmicos com massa, impulso, gravidade vertical, gavetas com trilhos e dobradiças simuladas ainda precisam de uma camada de corpos rígidos. A IA e a progressão narrativa originais foram preservadas nesta etapa. O jogo ainda precisa ser validado em execução no Electron e em diferentes GPUs.
